# 📊 Streamlit CSV til Excel Konverter

En simpel Streamlit app der kan:

1. Uploade en CSV-fil  
2. Konvertere den til Excel (XLSX)  
3. Downloade resultatet  

## 🚀 Sådan kører du appen lokalt

```bash
git clone https://github.com/<dit-brugernavn>/streamlit-csv-to-excel.git
cd streamlit-csv-to-excel
pip install -r requirements.txt
streamlit run app.py
